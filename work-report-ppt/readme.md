# 工作汇报 PPT（HTML 版 · 国风）

一个自包含的 HTML 幻灯片，**无需安装任何东西、无需联网**，浏览器打开即是可放映的工作汇报模板。共 10 页：

| 页 | 内容 |
|---|---|
| 1 | 封面（填写汇报人/部门/日期） |
| 2 | 目录 |
| 3 | 背景与目标 |
| 4 | 工作进展（时间线） |
| 5 | 数据指标 |
| 6 | 成果亮点 |
| 7 | 挑战与对策（表格） |
| 8 | 风险预警 |
| 9 | 下一步计划 |
| 10 | 致谢 |

## 怎么用

直接双击 `index.html` 用浏览器打开即可。

### 翻页操作

| 操作 | 效果 |
|---|---|
| 鼠标滚轮 / 点屏幕左右两侧 | 下一页 / 上一页 |
| `→` `PageDown` `空格` | 下一页 |
| `←` `PageUp` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| 底部圆点 | 跳到任意页 |
| `F` 键或「全屏」按钮 | 全屏放映 |
| 「首页」按钮 | 回到封面 |

### 改内容

所有要填的地方都留了 `__` 占位，用任意文本编辑器打开 `index.html` 搜索替换即可，改完刷新浏览器就生效。
重点改这几处：
- 第 1 页：封面信息（汇报人/部门/日期）
- 第 5 页：四个核心数字
- 第 4、7、9 页：时间线与表格里的具体内容

### 放映建议

- 正式汇报前按 `F` 进全屏，浏览器标签栏会隐藏，效果接近 PowerPoint
- 导出成 PDF 留档：浏览器 `Ctrl/Cmd + P` → 目的地选「另存为 PDF」，横向 A4
